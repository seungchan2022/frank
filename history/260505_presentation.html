01 · Hook 시스템

AI가 규칙을 지키지 않았다

SITUATION
AI가 인터뷰 질문을 다 하지 않고 갑자기 구현으로 직진하는 일이 반복됐다. 규칙 파일에 적어둬도 대화가 길어지면 그냥 잊어버렸다
SOLUTION
인터뷰가 끝나지 않으면 코드 파일 수정 자체를 훅으로 차단했다. 매 메시지마다 남은 질문도 자동으로 주입해 잊지 못하게 했다
RESULT
인터뷰 질문이 남아있으면 코드를 작성할 수 없다. AI는 차단 메시지를 읽고 스스로 인터뷰로 돌아온다
HOW IT WORKS
장치 1
상태 파일
active_step.txt
현재 몇 단계인지, 인터뷰가 몇 번째인지를 파일로 저장
대화가 바뀌어도 단계 정보 유지
장치 2
자동 주입
UserPromptSubmit
메시지를 보낼 때마다 현재 단계를 AI 컨텍스트 맨 앞에 자동으로 붙임
잊으려 해도 매번 다시 인식
장치 3
물리적 차단
PreToolUse hook
인터뷰가 끝나지 않으면 코드 파일 열기 자체를 막음
차단 메시지에 "남은 질문: ..." → AI가 읽고 스스로 인터뷰로 복귀
01 · /study 스킬

내 프로젝트인데 설명을 못했다

SITUATION
MVP를 계속 만들다 보니, 내가 만든 것인데도 흐름과 개념을 자연스럽게 설명하지 못했다
SOLUTION
아카이빙된 MVP 문서 기반으로, 개념을 무작정 외우는 대신 흐름 안에서 구간별로 익히는 스킬을 직접 만들었다
RESULT
로그인 흐름을 첫 대상으로 직접 써보며 보완했고, MVP 단위로 사이클을 반복할 수 있는 구조가 됐다
HOW IT WORKS
1
흐름도 생성 — Mermaid로 기능 전체 흐름을 먼저 시각화
2
구간별 개념 설명 — 흐름을 3~5개 구간으로 묶어 순서대로 설명
3
어드바이저 팩트체크 — 잘못된 개념이 섞이지 않도록 검증
4
퀴즈 — 한 문제씩 4지선다로 개념 확인
5
저장 — 흐름도 SVG + 학습 노트 MD로 아카이빙

02 · 기능 ① 퀴즈 풀기

스크랩 기사로 퀴즈를 만들어준다

기사를 저장하는 것에서 멈추지 않고, 실제로 이해했는지 확인하는 루프를 만든다

스크랩 → AI 퀴즈 생성 → 풀기 → 결과 저장
1
관심 있는 기사를 즐겨찾기로 저장
2
AI가 기사 핵심 내용 기반으로 퀴즈 자동 생성
3
퀴즈를 풀며 이해도 확인
4
틀린 문제는 오답노트에 자동 저장
02 · 기능 ② 오답노트 아카이빙

틀린 것만 자동으로 모아준다

틀린 문제만 따로 저장해 "내가 모르는 것" 리스트가 자동으로 쌓인다

오답노트에 저장되는 것
  • 틀린 문제 원문
  • 정답과 내 답
설계 의도
한 번 스크랩 → 퀴즈 → 반복 복습으로 이어지는 학습 루프
02 · 기능 ③ 직업별 재작성

"내 직업 관점"으로 기사를 다시 써준다

AI 요약이 아닌, 내 역할에서 바라본 해석이다

"AI 챗봇의 부상" 기사를  iOS 개발자 관점으로 재작성 → "내 앱에서 AI를 어떻게 쓸 수 있을까"
1
직업 설정 — iOS 개발자 / 마케터 / 디자이너 등
2
스크랩된 기사 중 원하는 기사 선택
3
AI가 직업 관점으로 재해석해서 출력
단순 AI 요약이 아닌
"나의 시각"이 반영된 콘텐츠

왜 필요했나?

UptimeRobot이 /health를 5분마다 호출 → Render 슬립 방지

But 기존 /health는 DB 조회 없음 → Supabase 7일 미사용 정지 위험

해결

DbPort에 ping() 추가 → SELECT 1 실행

UptimeRobot 핑 1번 = Render 슬립방지 + Supabase 유지 동시

Step 4 — 트러블슈팅 포함

iOS — 실기기 서버 URL 전환

Secrets.plist 수정

SERVER_URL → Render URL로 변경
→ 하지만 앱에서 여전히 macbook-pro.local로 요청

콘솔 로그로 원인 파악
NSErrorFailingURLStringKey= http://macbook-pro.local:8080/api/tags "The request timed out."
원인 발견: Config.xcconfig 우선순위

Info.plist → Secrets.plist 순서인데
Config.xcconfig가 Info.plist에 주입됨 → 우선 적용

Config.xcconfig 수정 → 해결 ✅
# Before SERVER_URL = http:$(SLASH)$(SLASH)MacBook-Pro.local:8080 # After SERVER_URL = https:$(SLASH)$(SLASH)frank-onvv.onrender.com

iOS 설정 파일 우선순위

1순위 Config.xcconfig → Info.plist에 주입
↓ 없으면
2순위 Secrets.plist

교훈: Secrets.plist만 바꿔서는 안 됨.
xcconfig가 있다면 그걸 먼저 확인해야 함.

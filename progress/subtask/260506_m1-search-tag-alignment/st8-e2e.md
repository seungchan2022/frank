# ST-8: E2E 시나리오 본인 직접 확인

> 유형: chore | 의존: ST-7 | 예상: 0.5h

## 목적

M1 DoD의 E2E 3가지 시나리오를 본인 직접 사용으로 통과 확인한다.

## 사전 준비

```bash
scripts/deploy.sh --target=api,front --native
# 또는
scripts/deploy.sh --target=api --native  # 서버만
```

배포 후 첫 피드 요청에 `Cache-Control: no-cache` 헤더를 포함하거나 앱에서 강제 새로고침으로 캐시를 플러시. 키워드 매핑 변경이 즉시 반영되도록 필수.

## 시나리오

### E2E-1: "모바일 개발" 탭 무관 기사 0건

1. 앱 열기 → 피드 → "모바일 개발" 태그 탭 클릭
2. 기사 전체 스크롤
3. 포켓몬/게임/의약품 등 무관 기사 카운트
4. **기준**: 0건

### E2E-2: 임의 태그 탭에서 한국어 기사 ≥1건

1. 임의 태그 탭 클릭 (예: AI/ML, 웹 개발)
2. 기사 목록에서 한국어 제목/출처 확인
3. **기준**: 1건 이상

### E2E-3: 태그-기사 매칭 일관성

> **주의**: 현재 `get_feed`는 URL 기준 중복 제거(`get_feed_deduplicates_by_url`)가 적용 중. 동일 기사는 첫 번째 태그에 귀속되어 다른 탭에서는 사라짐. 따라서 "같은 기사가 두 탭 동시 노출" 시나리오는 현재 아키텍처에서 발생하지 않음.

**대체 검증**: 태그별 기사가 해당 태그 맥락에 맞는지 확인.

1. "AI/ML" 탭 클릭 → 기사 전체 확인
2. 기사 제목·출처가 AI/ML 주제임을 육안 확인
3. "오픈소스" 탭 클릭 → 의약품/게임 기사 없음 확인
4. **기준**: 각 탭의 기사가 해당 태그 주제에 부합 (오분류 기사 0건)

### E2E-4: 전체 탭 순회 — 공동화/0건 탭 없음 확인

1. 전체 12개 태그 탭을 순서대로 클릭
2. 각 탭의 기사 수 기록
3. **기준**: 0건 탭 발생 없음 (include_domains 필터 부작용 감지)

## 알려진 한계 (Known Limitation)

- **A2 한국어 기사 0건**: Tavily API는 한국어 언론 기사를 인덱싱하지 않음. `tag_search_keyword()` 한국어 키워드 추가·`country` 파라미터 모두 효과 없음. → `DEBT-MVP16-05`
- **일부 태그 무관 기사 잔존**: "오픈소스" 탭 광업 기사, "웹 개발" 탭 NFL 기사가 E2E에서 간헐적으로 관측됨. 근본 해결은 `include_domains` 화이트리스트 → `DEBT-MVP16-04`
